# novel-engine

**[English](./README.md)**

在自己电脑上跑的**长篇写作软件**：用 AI 帮你写，但**不会**一键写完全书。

你先说清楚想写什么，程序只把**开头这一段情节**钉住，然后**一章一章**写。随时能改、能否、能重来。面向连载／网文节奏（章末钩子、分弧、别把前面的设定忘掉）。

- **作者：** [Huaji-Wang](https://github.com/Huaji-Wang)

## 这是什么、不是什么

**是：** 启动后浏览器打开的本地网站。左边是书单，中间是当前这本书的页签，右边是模型干活时的进度。

**不是：** 要注册的云账号、一键导出 epub 的工具，也不是开书当天就必须定好结局和总章数的系统。

---

## 第一次：从空白页写到第 1 章

先做完下面的 [快速开始](#快速开始)。蓝图生成会比较久，请预留时间。

1. 打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)，点 **＋ 新建**。
2. 填**书名**和**故事方向／创意**。每章字数可空着不管。若是已有作品的同人，勾选 **同人模式**。点 **创建**。
3. 进入 **① 蓝图**。这时还没有全书大纲。在 **开书共创** 里打字，点 **发送**，想聊几轮聊几轮。右边的 **创作指令草稿** 就是「之后生成必须遵守的说明书」。
4. 草稿可以了，点 **确认共创**，再点 **🚀 生成蓝图**。等右侧进度跑完。这时会有核心种子、角色关系、世界观、**只含第 1 弧**的架构、一份松的「指南针」，以及**最前面几章的细纲**。
5. 打开 **③ 细纲**，看第 1 章细纲。不满意就编辑或点 **AI 修订**。
6. 打开 **④ 章节**，在第 1 章点 **✍ 生成正文**。弹窗里的「本章额外指导」可留空。等任务结束。
7. 读正文。可用 **润色**、**去AI味**，或选中一段重写、**AI 修订**。你认可以后点 **定稿**。定稿会更新摘要和台账，后面的章才记得这一章发生了什么。

也可以跳过共创直接 **生成蓝图**；一般更容易写飘，因为模型只看见你那一两句创意。

## 界面上这些词是什么意思

| 你看见的 | 实际含义 |
|----------|----------|
| **① 蓝图** | 规划页：共创、写作指导、第 1 弧、指南针。这里**没有**章节正文。 |
| **开书共创** | 把想法聊成一份 Markdown **创作指令草稿**。用过共创的话，生成蓝图前请先 **确认共创**。 |
| **本轮思考** | 可折叠的短摘要（已理解／缺口／下一步）。只有模型接口**真的支持流式**时才出现。不会把这段思考再塞回下一轮给模型。 |
| **全局写作指导** | 三块：文风、视角、禁忌。都可以留空（等于跳过）。随时改，**之后新写的章**会跟新内容；**不必**为此重跑整份蓝图。 |
| **规模与类型** | 类型标签；**软估计总章数**。填 `0` 表示不锁死。这不是「全书只能写 20 章」的硬合同。 |
| **核心种子／世界观／第1弧架构** | 短规划文本。第 1 弧 = **近处**要演完的一段，不是整部书的三幕到结局。 |
| **故事倾向摘要／终局指南针** | **弱指南针**：结局大概往哪靠、有哪些长线、体量感觉。**不是**锁死的最后一章。可以改。 |
| **③ 细纲** | 每章给写作模型看的节拍。常有短的 **必做／禁做**。同人模式会要求禁做更严。 |
| **④ 章节** | 真正的正文。**定稿** = 「这一章算进记忆和台账」，不是发布到网站。 |
| **⑥ 全局状态** | 前文摘要、角色状态表，以及 **待确认**。章里新冒出来的人物／设定先停在这里，你点 **确认** 或 **拒绝**。 |
| **Jobs／断点** | 费时任务在后台跑。进程挂了可以从**已做完的步骤**接着，不必从头烧一遍 token。 |

## 第 1 章之后

- 细纲不够了，在细纲页点 **➕ 生成后续章节细纲**。
- 尽量按「写 → 改 → 定稿」走；不定稿，后面的章容易忘了刚发生的事。
- 当前卷／弧写满后，要用「追加卷／下一弧方向」。超出已规划范围时，程序会拦住，直到你延长规划或标记全书完结。
- **重新生成蓝图** 会覆盖规划（相关角色卡和细纲也会重建）。只在你真的打算推倒重来时用。

## 另外还有

确认共创后的同人**字段锁**；**⑤ 设定库**；伏笔／爽点台账；章节润色和健康检查。Community 的质量报告**偏松**：不会因为检查结果禁止定稿，也不会自动整章重写。

**本仓没有**（可能留给以后的托管版）：登录、付费、epub／批量导出、很重的长会话压缩。

## 快速开始

```bash
cd novel-engine
python -m venv .venv
# Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp config.example.yaml config.yaml   # Windows: copy config.example.yaml config.yaml
```

编辑 `config.yaml`：在 `llm.providers.<名称>.api_key` 填入 **OpenAI 兼容** 的密钥，并把该 provider 设为 `enabled: true`。保存后：

```bash
python run.py
```

打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)。

**不要提交 `config.yaml`。** 已在 gitignore 里，里面是密钥。

共创「本轮思考」仅当该 API 真正支持流式时开启；否则仍是整包回复，界面也不出现思考区。

## 质量门（Community）

- `block_finalize: false`
- `auto_rewrite_on_critical: false`
- `auto_humanize_on_fix: true`

本地可以加严。以后托管云端预计会更严。
