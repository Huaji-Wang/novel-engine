从下列开书共创草稿中抽取「类型 / 软篇幅 / 三块全局写作指导」。

只输出一个 JSON 对象，不要其它文字。字段：
{
  "genre": "频道/类型标签，如都市奇幻；未定则空字符串",
  "soft_num_chapters": 0,
  "guide_style": "文风语气要求；作者跳过或未定则空字符串",
  "guide_pov": "视角人称要求；跳过或未定则空字符串",
  "guide_taboos": "禁忌与硬要求；跳过或未定则空字符串"
}

规则：
- soft_num_chapters：仅当作者明确给出大致章数（如「大概 50 章」）时填正整数；说「不确定/开放/随便写」或未提及时填 0
- 三块指导：只收录作者明确确认的内容；草稿写「跳过」或未讨论则对应字段空字符串
- 不要把故事情节、人物小传塞进指导字段
- 不要发明作者没说过的禁忌
