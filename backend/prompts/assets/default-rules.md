# 机械可检规则（ainovel-cli assets/rules/default.md）

与上方【去 AI 味判据】互补：本文专管**可字面子串匹配**的套句与疲劳词；带变量的模式（如「不是 X 而是 Y」）字面匹配抓不到，归 anti-ai-tone.md 语义层。

> 项目内置默认规则（Phase 1 安全版）
>
> 这里只放「机械可检 + 低争议」的默认约束。非机械化审美偏好（如风格倾向）由 writer / editor prompt 与 anti-ai-tone.md 承载。
>
> 短语黑名单：出现 ≥1 次即 error。checker 做字面子串匹配，无通配符，故只放「定长固定串」的 AI 套句（低争议）。
> 破折号「——」在对话被打断时合法，有争议，不进内置默认，可另行自配。
>
> 疲劳词软限制：commit / 健康检查会检查每章出现次数，超过阈值报 warning。
> 这些是网文/小说常见过度使用的词，anti-ai-tone.md 有同方向的语义提示——双源信号一致。
> 后六条（像一/沉默了/没有说话/X息）来自 196 章长跑产物实证：传统套话已被上面的表灭绝，但模型转而把这些「节拍词」用到章均 5-7 次；阈值放宽容忍正常使用。

## forbidden_phrases（≥1 次即 error，改写后须清零）

- 某种程度上
- 值得注意的是
- 不知为何
- 五味杂陈
